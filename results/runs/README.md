# The run results

This directory is a copy of everything the experiment runs produced, with
the checkpoints left out and the paths made relative.  It exists so that a
reader can check a number against the file it came from without running
the training themselves.

## Layout

| Path | Contents |
|---|---|
| `<group>_s<seed>/train_summary.json` | the configuration, the wall time, and the reported validation accuracy of one seed |
| `<group>_s<seed>/eval_last.json` | the per-split accuracies of one seed, on the final checkpoint |
| `summary_<group>.json` | the same thing aggregated over the seeds of a group, with a `per_class` breakdown |
| `stats_report.json` | the paired comparisons, with confidence intervals and effect sizes |
| `summary_all_groups.json` | every completed group, ranked by cross-domain accuracy |
| `summary_line_art_comparison.json` | the line-art family, paired |
| `summary_line_art_mechanism.json` | the line-art ink statistics, measured before any training |
| `summary_ours_fg_center_comparison.json` | the foreground comparison, paired |
| `foreground_selection.json` | the Photo Validation gate and the mechanism ranking |
| `structure_metrics_*.json` | the EdgeScore and LPIPS measurements |

## What was changed on the way in

Two things, both mechanical:

- **The checkpoints were not copied.**  They are 43 MB each and are
  regenerated by `train.py` from the recorded configuration; the
  `config_hash` in each summary identifies which configuration that was.
- **The paths were made relative.**  A recorded manifest path named the
  absolute directory of the machine that produced the run.  It is now
  relative to the data root, like the rest of the repository.

Nothing else was touched: the accuracies, the paired statistics and the
configuration hashes are the values the runs produced.

## Reproducing a run

```powershell
# export the results of a fresh run into this directory
.\nn.ps1 member4_training_eval\export_run_results.py

# regenerate the ranking table from the results
.\nn.ps1 member4_training_eval\summarize_all_groups.py
```

The generator of the export is
[`export_run_results.py`](../member4_training_eval/export_run_results.py),
and it reads the same `$NNDL_RUNS_ROOT` the training writes to.
