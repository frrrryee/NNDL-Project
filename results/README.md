# Recorded Results

These are the recorded results of every reported run.  They are the single
source of truth for every number in the report: no figure is re-typed by
hand, and every table can be regenerated from these files.

Checkpoints (`*.pt`) and the PACS images are **not** in the repository.  They
are reproducible from the frozen protocol: the same code, the same split
files, the same style pool and the same `config_hash` regenerate them.

## What is here

| File | Contents |
|---|---|
| `summary_original.json` | Original group, 3 seeds |
| `summary_adain.json` | +AdaIN (uniform, α=0.5) |
| `summary_adain_matched.json` | +AdaIN (strength-matched, mean α=0.374) |
| `summary_ours.json` | +Ours (spatial modulation, mean α=0.374) |
| `summary_ours_equal.json` | +Ours (spatial modulation, mean α=0.500) |
| `stats_report.json` | Paired comparisons, confidence intervals, effect sizes |
| `structure_metrics_*.json` | EdgeScore and LPIPS per augmentation set |
| `edge_analysis.npz` | Per-image edge scores for the 1,349 training images |
| [`runs/`](runs/) | **Every run's raw results** — per-seed records, the full group ranking, the line-art and foreground comparisons, and the selection record. See [its README](runs/README.md). |

Each `summary_*.json` contains, for every split: the mean, the standard
deviation and the per-seed accuracies, plus a `per_class` breakdown.  The
`config_hash` recorded in each file identifies the training configuration;
all five groups share `ecc6090e5b29`.

## Regenerating the tables

```powershell
# the headline table, the paired comparisons and the strength/accuracy curve
.\nn.ps1 member4_training_eval\final_analysis.py

# the results table in LaTeX or Markdown
.\nn.ps1 member4_training_eval\summarize_results.py --format latex
.\nn.ps1 member4_training_eval\summarize_results.py --format markdown

# every completed group, ranked by cross-domain accuracy
.\nn.ps1 member4_training_eval\summarize_all_groups.py

# copy the results of a fresh run into results/runs/
.\nn.ps1 member4_training_eval\export_run_results.py
```

`final_analysis.py` and `summarize_results.py` read the summaries from
`$NNDL_RUNS_ROOT`.  After a fresh run, copy the new summaries here so the
repository stays in sync with the results.

`export_run_results.py` does that copy for the whole runs directory: it
takes every result file, leaves the checkpoints out and rewrites the
absolute paths as relative ones.

## What is not here, and why

| Missing | Size | Why |
|---|---|---|
| PACS images | ~1 GB | the dataset; each member downloads it separately |
| `*.pt` checkpoints | 43 MB each | regenerated by `train.py` from the recorded config |
| `member2_adain/models/*.pth` | 90 MB | VGG and decoder weights; regenerated by `build_style_pool.py` |
| Generated augmented images | ~120 MB per set | regenerated from the frozen style pool and pairing |

## Reproducing a reported number

1. Put the PACS images where `NNDL_DATA_ROOT` points.
2. Regenerate the augmentation sets with the recorded parameters
   (`member2_adain/build_adain_aug.py`, `member3_structure_preserving/generate.py`).
3. Train with `run_all.py --group <group> --seeds 0 1 2`.
4. Check `config_hash` matches `ecc6090e5b29`; `fairness_check.py` will
   refuse to accept a run produced under a different configuration.
