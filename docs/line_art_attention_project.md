# 线稿增强 + 注意力软门控 + 色块软投票

**项目文档 v1.1** · 2026-11-24 · 状态：**前置检查已通过**，等待 P1 生成数据集

## 0. 一页摘要

| 项 | 内容 |
|---|---|
| **目标** | 检验"形状偏置增强能否提升 PACS 跨域泛化"，并回答"我们空间调制失败的根因是否在于缺少形状约束" |
| **核心想法** | 用**线稿**（而非风格化图）作为增强，线稿强度由**注意力语义**决定，画线位置由**色块（超像素）几何**决定 |
| **关键创新点** | 两个信号**分工**而非投票：色块回答"边界在哪"，注意力回答"这条边值不值得画" |
| **成本优势** | **完全不需要 AdaIN**，不抢 GPU，可与 Batch B / `ours_fg` 并行 |
| **预计总成本** | 前置检查 15 min + 生成 15 min + 训练 40 min ≈ **1 小时** |
| **主要风险** | 捷径学习（模型学会"输入是线稿就走形状分支"） |
| **决定性诊断** | Photo Val 涨但跨域不涨 → 捷径学习，方案无效 |
| **可证伪预测** | 增益应**集中在 Sketch 域**，而非均匀分布于三个目标域 |

## 1. 动机：为什么要做这件事

### 1.1 我们已经知道的事

**主结果（已完成，5 种子）**：跨域准确率 `ours` 44.5% < `adain_matched` 45.2%。空间调制**没有**超过匹配均匀 AdaIN 对照。

**机制诊断（已完成）**：这不是实现 bug，而是**地图语义反了**。

- Sobel 边缘响应 $M$ 有 49.1% 的质量落在弥散中段（0.2–0.8），只有 3.0% 在最高 1% 像素
- 结果：背景纹理 $\to$ 高 $M$ $\to$ 低样式强度；物体轮廓 $M\approx 0$ $\to$ **全额样式伤害**
- **62.9% 的图像**（849/1349）中，空间变体保留的边缘**少于**匹配对照
- 公式 $\alpha=\alpha_0(1-\beta M)$ 本身没错，**错的是 M 代表了纹理而非物体**

**修复尝试（`ours_fg`，已完成生成 + 机制测量）**：

| | 原方法（Sobel） | 修复版（前景显著度） |
|---|---|---|
| EdgeScore 相对匹配对照 | **−0.0031** | **+0.0009** |
| 保留更差的图占比 | 62.9% | **45.6%** |
| 7 个类别符号 | 全负 | **全正** |

**符号翻转了，但幅度极小**（EdgeScore 本身在 0.32–0.36 量级，0.0009 只是 0.3% 相对量）。

### 1.2 幅度为什么这么小 —— 这是本文档的出发点

量化原因：**`spectral` 前景图只有 2–3% 的像素高于 0.5**（Sobel 是 11–26%）。

也就是说 `ours_fg` 只保护了物体**最有辨识度的一小块**（比如吉他的琴身），**物体的大部分仍在吃满额样式**。

**这就是本项目的核心诊断：不是"要不要空间调制"，而是" modulating map 的覆盖率和语义精度够不够"。**

### 1.3 文献定位（重要）

**Domain Generalization Emerges from Dreaming**（Stylized Dream, ICLR 2023, [arXiv:2302.00980](https://arxiv.org/abs/2302.00980)）

- 同样用 AdaIN 做风格增强，目标同样是**降低 texture bias、逼迫形状表征**
- 覆盖 PACS / VLCS / OfficeHome / TerraIncognita / DomainNet，报 SOTA
- **但它靠的是一致性正则**（原图与风格化图输出一致），不是空间调制

> **我们与它缺的那块拼图**：我们做纯数据增强，**没有约束模型对原图和风格化图给出一致的预测**，所以"增强 → 迫使形状学习"这条因果链没有闭合。

**ShapeBlend**（CVIU 2026, [doi](https://doi.org/10.1016/j.cviu.2026.104768)）—— CORF 轮廓图与原图**软混合**强调轮廓，ImageNet-A/R/C 刷 SOTA。**证明"轮廓增强"是成熟方向**。

**Shape Guided Gradient Voting**（[arXiv:2306.10809](https://arxiv.org/pdf/2306.10809v1)）—— 边缘/线稿作为额外输入提供形状引导 + 纹理增强作隐式引导。

**Shape-Biased DG via Shock Graph Embeddings**（ICCV 2021）—— **纯形状**（不含外观）在 PACS 上超过 ImageNet CNN 基线。**形状偏置在 PACS 上确实有用的最强证据**。

**结论**：线稿/轮廓增强在 PACS 上有独立且成熟的先例，且与我们的主线**互补而不冲突**。

## 2. 方法设计

### 2.1 两个信号，两个失败模式

| 信号 | 提供什么 | 单独使用的已知问题 |
|---|---|---|
| **注意力**（ImageNet 预训练 ResNet-18 的 CAM，取所有类最大值） | **语义** —— 物体在哪 | 7×7 特征图上采样，边界糊；逐类不稳定（`house`/`person` 是重灾区） |
| **色块**（SLIC 超像素） | **几何精度** —— 边界在哪、贴合图像结构 | 边界 ≈ 颜色不连续处 ≈ 边缘检测器 = **我们的 Sobel M，同一个病** |

单独用色块会退化成我们刚证伪的东西。**但用注意力去门控它**，就把它从"边缘检测器"变成了"物体轮廓定位器"。

### 2.2 融合方式：区域级，不是像素级

**原始提案**：像素级投票（每像素拿注意力分和色块分各投一票）。

**建议调整**：让色块当容器、注意力当权重。理由是像素级投票会让两个语义不同的信号在同一尺度上竞争，产生折中；而区域级分工让每个信号做它擅长的事。

具体流程：

```
1. SLIC 超像素分割 → 区域标签 S₁..S_K
2. 每个超像素的语义分 m_k = 其内部注意力的均值
3. 在超像素边界上画线，线的暗度由边界两侧区域的 m 决定：
     · 物体↔物体边界（内部部件：身/腿）  → 强线
     · 物体↔背景边界（外轮廓）           → 强线
     · 背景↔背景边界（纹理）             → 淡线
4. 背景轮廓保留为淡线而非删除
```

**两个信号的分工变得清晰**：

- 色块回答：**边界在哪**（像素级精度，贴合图像结构）
- 注意力回答：**这条边值不值得画**（语义级判断）

**保留背景淡线的理由**：分类器可能需要上下文——"马上的人"和"草地上的马"是不同的图。硬二值掩码会把这些信息删掉，软门控渐进降级则保住了它。**这是软门控相对硬掩码的实质优势**，也是与 ShapeBlend 的软混合思路一致的地方。

### 2.3 注意力来源与合法性

**选择：ImageNet 预训练 ResNet-18 的 CAM-objectness**

- 取**所有 1000 个 ImageNet 类**的 CAM 的**最大值**，而非类别对应的那一个
- **不使用类别标签** → 增强生成不依赖标签，而标签正是分类器要推断的东西
- ImageNet 不含 PACS（可验证），零样本迁移
- **我们已经有这个模型**（`model.py` 的 `build_model`），零下载、零额外训练
- 推理 1349 张约 **2 分钟**

**为什么不选 SAM / DINO**：

| 方案 | 问题 |
|---|---|
| SAM | SA-1B 训练集明确包含大量照片，审稿人会问"是否见过 PACS 图像"。**ImageNet 是分类数据集，可验证不含 PACS，更安全** |
| DINO ViT | 语义更强，但 16×16 patch 网格粗、已知有 artifact（关注背景和高范数 patch），需多层平均 + rollout；且需下载 85MB 权重 |
| DINO ViT-S/8 | 边界更好，但权重更大（~85MB），推理更慢 |

**若后续需要更强地图**：DINO 的 [CLS] 自注意力图直接给无监督分割（[arXiv:2109.14279](https://arxiv.org/abs/2109.14279)，PASCAL VOC 45.9 Jaccard vs 监督 ViT 27.3），官方 `visualize_attention.py` 有"按注意力累积质量阈值取掩码"的现成实现。

### 2.4 输出产物

每个内容图生成：

| 文件 | 内容 | 作用 |
|---|---|---|
| `line_attn` | 注意力门控线稿（**主方案**） | — |
| `line_plain` | 同参数但**无门控**（所有边界同暗度） | **匹配对照** |

**匹配对照是强制的**：`line_plain` 回答"注意力门控本身有没有用"，排除"线稿图更简单所以更好学"这个混淆。

| 单元 | 内容 | 隔离的问题 |
|---|---|---|

**训练协议**（完全沿用主表，不改任何超参）：

- ImageNet 预训练 ResNet-18 + 7 类头
- SGD lr=0.01，momentum=0.9，wd=5e-4，label_smoothing=0.1，CosineAnnealing
- 660 步，batch 64，`RandomResizedCrop(224, scale=(0.7,1.0))` + 水平翻转

- 5 个种子 (0,1,2,3,4)
- **独立 config_hash**（同 MixStyle / `ours_fg` 的纪律）

## 5. 判据与风险控制

### 5.1 决定性诊断：捷径学习

**风险**：线稿图是**更容易的任务**（干净形状、高 val 准确率）。若无一致性正则，模型可能学成"输入是灰度线稿走形状分支、输入是照片走纹理分支"——**这是路由捷径，不是不变性**。

Stylized Dream 用原图/风格化图一致性损失堵这个洞；我们这条线目前没有。

**判据**：

| Photo Val | 跨域准确率 | 结论 |
|---|---|---|
| 明显高于 `original` | **不涨** | ⚠️ **捷径学习签名，方案无效** |
| 和 `original` 相当 | 涨 | ✅ 真的不变性，方案有效 |
| 涨 | 涨 | ✅✅ 最理想 |

这个判据和"我们 vs 匹配对照"是同一套逻辑。

### 5.2 可证伪预测：增益应集中在 Sketch 域

PACS 的 Photo → Sketch 恰恰就是**形状偏置**的故事（素描只保留形状，去掉全部纹理和颜色）。Stylized Dream 也测到 Photo→A 只有 63.78% 而 A→P 有 91.44%。

**预测**：若线稿增强真的在建立形状偏置，增益应**集中在 Sketch 域**，而非均匀分布于三个目标域。

- 对上了 → 机制假设成立，方向明确
- 没对上（均匀或集中在别处）→ 增益来自别的东西，这条路该关

**诚实性要求**：若增益意外出现，要警惕它可能在"蹭" Sketch 域的分布特性（线稿形态本就接近 Sketch 域）。报告应写成"形状偏置增强恰好与某个目标域的统计特性接近"，而非当成方法优势。

### 5.3 选参信号不足（已知卡点）

Photo Val 已饱和：7 个组挤在 **98.13%–98.93%**，总跨度 2.00 点，而验证集**一张图值 0.67 点**，种子内 std 0.30–0.60%。

**影响**：Photo Val 只能做**安全门**（排除明显更差的候选），不能做排序。

**补救（可选）**：在 Photo 内部构造**伪域**（pseudo-domain）做留一验证，估"方法对源域特有外观的过拟合程度"——完全合法（不碰目标域），且比饱和的 Photo Val 有区分度。

## 6. 纪律红线

### 6.1 绝对禁止

- ❌ **不得用 PACS sketch 域的任何图像**——sketch 是目标域，用它训练或训提取器都是目标泄漏
- ❌ **不得用类别标签取 CAM**——必须用所有类的最大值，保持增强与标签无关
- ❌ **不得改主表已有组的任何数字**——新单元独立 tag、独立 config_hash、独立报告
- ❌ **不得覆盖主哈希** `ecc6090e5b29`

### 6.2 必须做

- ✅ 线稿只从 **Photo 原图**用无监督变换提取
- ✅ ImageNet 先验只用于**生成增强图**，不参与分类器训练、不做任何目标域选择
- ✅ 每个新单元配**自己的匹配对照**
- ✅ 5 个种子，报告均值 ± 标准差
- ✅ 新单元只在**自己的报告小节**里出现，不进主表当"我们的方法"

### 6.3 归因边界（重要）

线稿增强测的是**另一条假设**（形状偏置），**不是** `ours` 的空间调制。它与 `ours_fg` 是**并列的独立实验**，不是改进。

**如果它涨了**，结论是"形状偏置有用，但空间调制不是正确载体"——**这依然是有价值的负结果**，且直接指向 Stylized Dream 那种一致性损失的路线。
